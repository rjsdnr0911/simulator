# 💰 StockCoin Simulator

실전 같은 주식 & 코인 트레이딩 시뮬레이터

## 🎮 소개

StockCoin Simulator는 주식과 암호화폐 거래를 시뮬레이션할 수 있는 웹 기반 게임입니다. 실시간 가격 변동, 뉴스 시스템, 시장 분위기 등 실제 거래 환경을 체험할 수 있습니다.

## ✨ 주요 기능

### 💹 트레이딩 시스템
- **19개 주식 종목** - 6개 섹터(기술, 자동차, 금융, 엔터테인먼트, 소비재, 제조)
- **10개 암호화폐** - 비트코인, 이더리움 등 주요 코인
- **실시간 가격 변동** - 주식 1분, 코인 20초 주기
- **매수/매도 시스템** - 수수료 포함 실제 거래 환경
- **포트폴리오 관리** - 보유 종목, 손익 현황 추적

### 📰 뉴스 & 시장 시스템
- **자동 뉴스 생성** - 10분마다 섹터별 뉴스 발생
- **뉴스 영향력** - 뉴스가 해당 종목 가격에 영향
- **시장 분위기** - 강세장, 약세장, 박스권, 고변동성
- **뉴스 명확도** - 난이도별로 힌트 수준 다름

### 🎯 난이도 시스템
- **쉬움** - 시작 자금 5천만원, 낮은 변동성, 명확한 힌트
- **보통** - 시작 자금 1천만원, 보통 변동성, 보통 힌트
- **어려움** - 시작 자금 500만원, 높은 변동성, 모호한 힌트, 파산 가능
- **커스텀** - 모든 설정 직접 조정

### 📊 분석 & 통계
- **거래일지** - 모든 거래 기록 및 손익 추적
- **통계 시스템** - 승률, 총 손익, 최대 수익/손실
- **포트폴리오 분석** - 다양성 점수, 리스크 레벨
- **추천 시스템** - 포트폴리오 기반 조언

### 🔔 알림 시스템
- 가격 변동 알림 (±5%, ±10%)
- 중요 뉴스 알림
- 보유 종목 관련 뉴스 알림
- 시장 분위기 변경 알림
- 자산 목표 달성 알림

### ⚙️ 게임 설정
- **시간 배속** - 1배속, 2배속, 5배속
- **저장/불러오기** - 로컬스토리지 자동 저장
- **알림 커스터마이징** - 원하는 알림만 받기
- **디버그 모드** - 개발자 도구

### ⌨️ 키보드 단축키
- `Space` - 일시정지/재개
- `S` - 게임 저장
- `Esc` - 모달 닫기
- `1-5` - 탭 전환 (주식/코인/포트폴리오/거래일지/통계)

## 🚀 시작하기

### 설치 방법

1. 저장소 클론
```bash
git clone <repository-url>
cd simulator
```

2. 웹 서버 실행
```bash
# Python 3
python -m http.server 8000

# Node.js (http-server)
npx http-server -p 8000
```

3. 브라우저에서 열기
```
http://localhost:8000
```

### 빌드 없이 실행

이 프로젝트는 순수 HTML/CSS/JavaScript로 작성되어 별도의 빌드 과정이 필요 없습니다. 파일을 그대로 웹 서버에서 제공하면 됩니다.

## 🎮 게임 플레이 가이드

### 기본 흐름

1. **난이도 선택** - 시작 화면에서 원하는 난이도 선택
2. **종목 탐색** - 주식/코인 탭에서 원하는 종목 확인
3. **매수** - 종목 상세 화면에서 수량 입력 후 매수
4. **뉴스 확인** - 상단 뉴스 티커로 시장 상황 파악
5. **매도** - 포트폴리오에서 적절한 타이밍에 매도
6. **통계 확인** - 거래일지와 통계로 성과 분석

### 팁

- 📰 **뉴스를 항상 주시하세요** - 가격에 직접적인 영향을 미칩니다
- 🌡️ **시장 분위기를 확인하세요** - 강세장/약세장에 따라 전략을 조정하세요
- 💰 **분산 투자하세요** - 여러 종목에 투자하면 리스크를 줄일 수 있습니다
- 💸 **수수료를 고려하세요** - 잦은 거래는 수수료 부담이 큽니다
- ⏱️ **타이밍이 중요합니다** - 손절/익절 타이밍을 잘 잡으세요
